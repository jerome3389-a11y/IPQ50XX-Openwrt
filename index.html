01

NSS 加速

转发由 NSS 硬件处理。

NSS 是 Qualcomm 的网络加速硬件，开启后转发在硬件里完成，CPU 不参与转发。

99 Mbps基线 #35 在 100M 宽带上的实测，CPU 平稳。

02

HE160

5GHz，160MHz，信道 36。

5GHz 支持 160MHz 频宽，CN、信道自动（实测 ch36）。

在中国，160MHz 只能走信道 36（没有 100–144）。

03

两个 ath11k 补丁

构建 #45 里的两处无线驱动改进。

补丁 A · 稳定性

RX 分片 double-free 修复

修复接收分片处理中的 double-free，防止极小概率的崩溃。

补丁 B · 2.4G

2GHz 报 7935 字节 A-MSDU

2.4G 聚合上限提升，吞吐可能变好。

两个补丁已在构建 #45 的二进制里验证通过，尚未刷机。

FAQ

常见问题

适用哪些板本？

适用于 M79A / M81。

NSS 是什么？

NSS 是 Qualcomm 的网络加速硬件。开启后，网络转发由 NSS 硬件处理，减轻 CPU 负担。

构建 #45 现在是什么状态？

已构建，未刷机验证。

和原厂固件有什么区别？

这是基于 OpenWrt 的第三方固件，带 NSS 硬件加速和更新的无线支持；原厂固件是小米提供的官方系统。

在哪里下载？

按板本下载最新版：M79A 最新、M81 最新；也可以在 GitHub Release 列表里自己选。
